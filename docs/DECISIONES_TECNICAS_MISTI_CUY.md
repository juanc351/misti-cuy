# DECISIONES TÉCNICAS - MISTI CUY

## Introducción

Este documento registra las decisiones importantes tomadas durante el desarrollo del proyecto Misti Cuy.

Cada decisión debe incluir:

- Fecha.
- Decisión tomada.
- Motivo.
- Beneficios.
- Posibles consecuencias.

---

# Decisión 001

## No utilizar carrito de compras en la primera versión

### Fecha

Julio 2026

### Decisión

La primera versión de Misti Cuy no tendrá carrito de compras ni pagos online.

La venta se realizará mediante contacto directo por WhatsApp.

### Motivo

La comercialización de cuyes requiere comunicación personalizada.

Antes de comprar, el cliente necesita conocer:

- Disponibilidad.
- Peso.
- Edad.
- Línea genética.
- Ubicación.
- Coordinación de entrega.

### Beneficios

- Mayor interacción con clientes.
- Permite explicar mejor el producto.
- Reduce complejidad inicial.
- Facilita validar el modelo de negocio.

---

# Decisión 002

## Utilizar Next.js como framework principal

### Fecha

Julio 2026

### Decisión

El frontend será desarrollado utilizando Next.js.

### Motivo

Next.js permite:

- Buen rendimiento.
- SEO avanzado.
- Renderizado optimizado.
- Escalabilidad.
- Integración sencilla con servicios externos.

### Beneficios

La página podrá posicionarse mejor en buscadores y crecer con nuevas funcionalidades.

---

# Decisión 003

## Utilizar Supabase como backend inicial

### Fecha

Julio 2026

### Decisión

La base de datos y servicios backend utilizarán Supabase.

### Motivo

Permite desarrollar más rápido sin construir un backend desde cero.

Incluye:

- PostgreSQL.
- Autenticación.
- Seguridad.
- APIs.
- Gestión de usuarios.

---

# Decisión 004

## Diseño orientado a celulares primero

### Fecha

Julio 2026

### Decisión

La página será desarrollada bajo metodología mobile-first.

### Motivo

La mayoría de clientes llegarán desde:

- Facebook.
- TikTok.
- WhatsApp.

Principalmente desde teléfonos móviles.

### Beneficios

- Mejor experiencia del usuario.
- Mayor velocidad.
- Mejor conversión.

---

# Decisión 005

## Utilizar inteligencia artificial como apoyo de desarrollo

### Fecha

Julio 2026

### Decisión

Se utilizarán herramientas de inteligencia artificial como apoyo para:

- Arquitectura.
- Generación de código.
- Documentación.
- Optimización.

### Motivo

Acelerar el desarrollo manteniendo revisión humana.

### Regla

Todo código generado por IA debe ser revisado antes de incorporarse al proyecto.

---

# Decisión 006

## La web será el centro del ecosistema digital

### Fecha

Julio 2026

### Decisión

La página web será el punto central donde convergerán:

- TikTok.
- Facebook.
- WhatsApp.

### Motivo

Las redes sociales generan atención, pero la página web genera confianza y organización.
